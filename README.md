# RouleJuste

Simulateur gratuit pour les livreurs à moto : on entre le prix affiché d'une course et la distance, l'outil enlève la commission, l'essence et l'usure, et dit si la course vaut le coup.

Outil indépendant, non affilié à aucun service de livraison.

## Mettre en ligne avec GitHub Pages

1. Pousser ce dossier dans un dépôt GitHub **public**.
2. Dans le dépôt : Settings › Pages › Source : branche `main`, dossier `/ (root)`.
3. Le site est disponible à `https://<ton-nom>.github.io/<nom-du-depot>/`.
